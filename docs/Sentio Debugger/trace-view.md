Sentio provides a trace view of a transaction.

## Trace modes and options

### Trace mode

Full trace mode includes cross-contract calls (CALL) and in-contract calls (JUMP).

<Image align="center" border={false} caption="Full Trace" src="https://media.githubusercontent.com/media/sentioxyz/docs/HEAD/assets/image%20(18).png" />

You can also hide in-contract calls (JUMP) by turning off Full trace.

### Options

Users can hide static calls and select the level of trace displayed.

<Image align="center" border={false} caption="Trace levels" src="https://media.githubusercontent.com/media/sentioxyz/docs/HEAD/assets/image%20(6).png" />

## Call Graph

Sentio provides the call graph that shows the contract interactions within a transaction.
